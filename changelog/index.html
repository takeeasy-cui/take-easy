v1.0 最新 正式版 2026-10-21
  • V1.0 正式版（应用 0x39d6e0）：USB 读卡模式自愈——电脑未弹出磁盘也能安全结束并再次打开，结束后导航恢复正常
  • 天气全面增强：连 WiFi 后首页 10 秒内自动更新；设置页新增「手动更新」按钮；失败时直接显示具体原因；修复中文城市名无法请求的问题；内置默认配置（心知天气 + 北京），「恢复默认源」即用
  • 移除临时截图功能，电源键短按恢复锁屏

  • 应用体积较 b19 缩小 36 KB
v1.0-b19 2026-10-19
  • 首个公开版本（应用 0x3a67a0）：YanReader 输入法引擎上线——全拼 / 九宫格拼音、候选翻页、联想、用户词典学习
  • 阅读数据面板恢复底部导航栏；备忘录支持整卡点击进入，编辑器全新重做
  • 天气：接入心知天气三天预报，主页天气区显示图标 / 地点 / 高低温，可配置地点与密钥
  • 键盘「确定」先选词再保存，杜绝拼音组合丢失；保存地点后首页立即显示
  • 锁屏四样式：票根 / 壁纸 / 时钟（黄历 + 待办）/ 计算器，锁屏密码与计算器锁屏绑定

  • GameCore 游戏内核与逆转裁判插件（游戏包放 TF 卡 games 目录即可）
  • WiFi / 热点 / USB 读卡 / 微信四路传书；在线刷机页支持浏览器直连烧录
