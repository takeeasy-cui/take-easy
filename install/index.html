网页刷机支持哪些浏览器？
桌面版 Chrome 或 Edge。网页刷机依赖 Web Serial API，Safari、Firefox 与手机浏览器暂不支持。
刷写会清空我的书籍和文件吗？
刷写只写入设备闪存，不处理 TF 卡。选择「完整安装」会擦除设备内部 Flash 并写入完整镜像，操作前仍建议备份重要数据。
连接后找不到设备怎么办？
确认使用可传输数据的 USB 线，关闭占用串口的其他程序；在设备「设置 → 升级和恢复 → BOOT 刷机」进入 BOOT 模式后再连接。
页面停在旧画面，是不是刷写失败了？
电子纸可能保留上一次画面。以网页进度与设备重新启动为准，必要时断电重启一次。
刷机有风险吗？会失去官方保修吗？
刷写属自主操作，存在一定风险；写入前请备份重要数据。刷入非官方固件可能影响原厂保修，请自行斟酌。TF 卡上的书籍与文件不受影响。
