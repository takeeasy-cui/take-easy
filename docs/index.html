Take Easy 使用说明

适用设备：小纸 Pico（RDP-G01-W） · 写作中，请根据实际功能补充各章节

开始前，说清楚这几件事

设备与风险：本固件仅适用于小纸 Pico（RDP-G01-W）。刷写属自主操作，存在风险；操作前请备份重要数据，刷入非官方固件可能影响原厂保修。
两种刷机方式选哪个？第一次安装或修复系统，用网页在线刷机的「完整安装」；已在使用本固件，用「固件升级」或 TF 卡升级，均保留数据。

快速上手

  1. 准备一张 FAT32 格式的 TF 卡，插入设备。
  2. 用 USB 数据线连接电脑，打开 在线刷机 页写入固件。
  3. 把 EPUB / TXT 放入 TF 卡 Books/ 目录，把字体放入 Fonts/ 目录。
  4. 重启设备，在书库中打开一本书即可阅读。

传书方式

方式步骤
Wi-Fi 传书设备开启 Wi-Fi 传书 → 手机/电脑连接同一网络 → 浏览器打开设备显示的地址 → 上传文件
USB 传输设备开启 USB 文件传输 → 电脑直接复制文件到 TF 卡目录
读卡器取出 TF 卡，用读卡器在电脑上复制文件

固件升级

连接设备，进入在线刷机页重新安装即可；安装默认保留设备设置与阅读数据，TF 卡书籍与文件不受影响。

目录结构（TF 卡）

TF 卡/
├── Books/       # 书籍（EPUB、TXT）
├── Fonts/       # 字体（TTF / OTF，建议附带许可证）
└── LockScreens/ # 锁屏图片（可选）

常见问题

书里的字显示成方框？
内置字体只含部分常用汉字。请放入一款完整的中文字体到 Fonts/ 目录，并在排版菜单中切换。
PDF 打不开？
请查阅你的固件支持格式。复杂、超容量或缺少内嵌中文字体的文档可能无法打开。
如何备份配置？
在设备「设置 → 配置备份」中导出。书籍、字体等文件仍需单独保留在 TF 卡上。
