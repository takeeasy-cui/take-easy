在线刷机

浏览器直连设备写入固件，无需安装任何驱动。适用于首次安装与日常升级。

设备确认：本刷机工具仅适用于 小纸 Pico（RDP-G01-W） 墨水屏设备。请勿对其他任何设备使用，否则可能造成不可修复的损坏。
  • 写入会替换设备上现有的系统：需要回到官方系统时，请先阅读官方的构建与烧录说明。
  • 「完整安装」会整片覆盖设备闪存（含引导程序与分区表）；无论设备现在运行什么系统都可以直接安装，TF 卡不受影响。
  • 设备电量充足，或保持 USB 供电。
  • 重要数据已备份，刷机期间不要拔线。

需要：设备一台 · 可传输数据的 USB 线 · 桌面版 Chrome 或 Edge 的电脑。

用 USB 线连接电脑，点击「连接设备」，在浏览器弹窗里选择墨水屏设备对应的串口。写入期间请保持页面打开、电脑唤醒、数据线不动。

找不到串口，或连接后无法写入？
先唤醒设备并保持 USB 连接；退出设备的 USB 读卡模式，关闭占用串口的其他程序（串口监视器、其他浏览器标签等）。仍未解决时，在设备「设置 → 升级和恢复 → BOOT 刷机」进入 BOOT 模式，再重新连接。也可以换一根支持数据传输的 USB 线、换一个 USB 接口后重试。

网页刷机支持哪些浏览器？
桌面版 Chrome 或 Edge。网页刷机依赖 Web Serial API，Safari、Firefox 与手机浏览器暂不支持。
刷写会清空我的书籍和文件吗？
刷写只写入设备闪存，不处理 TF 卡。选择「完整安装」会擦除设备内部 Flash 并写入完整镜像，操作前仍建议备份重要数据；TF 卡上的书籍与文件不受影响。
连接后找不到设备怎么办？
确认使用可传输数据的 USB 线，退出 USB 读卡模式，关闭占用串口的其他程序；在设备「设置 → 升级和恢复 → BOOT 刷机」进入 BOOT 模式后再连接。
写入中断了怎么办？
保持供电，重新连接并再安装一次。无法连接时，按上方说明进入 BOOT 模式，再重新选择串口刷写。
页面停在旧画面，是不是刷写失败了？
电子纸会保留旧画面，以网页进度条为准。若设备按键毫无反应（偶发是重启时停在烧录待命模式），拔掉 USB 线重新插上即可恢复正常启动；必要时长按电源键强制重启。
「固件升级」和「完整安装」有什么区别？
「完整安装」写入全部镜像，适合首次安装、修复系统或从其他固件切换；「固件升级」仅更新应用与启动数据，适合已在本固件 1.0 系列上升级，保留设置与数据。
刷机有风险吗？会失去官方保修吗？
刷写属自主操作，存在一定风险；写入前请备份重要数据。刷入非官方固件可能影响原厂保修，请自行斟酌。TF 卡上的书籍与文件不受影响。
