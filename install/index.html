在线刷机

浏览器直连设备写入固件，无需安装任何驱动。适用于首次安装、修复系统与切回本固件。

设备确认：本刷机工具仅适用于 小纸 Pico（RDP-G01-W） 墨水屏设备。请勿对其他任何设备使用，否则可能造成不可修复的损坏。
  • 安装写入引导程序、分区表、应用与输入法词库；默认保留设备设置与数据（安装弹窗里不要勾选「擦除设备」），TF 卡不受影响。
  • V1.0.2 更新了分区布局：从旧版本重新刷机后，机内书区会重建一次（机内存放的书需重新传入）；TF 卡书籍与设置不受影响。输入法词库（精简版）随刷机内置，中文输入开箱即用。
  • 设备电量充足，或保持 USB 供电。
  • 重要数据已备份，刷机期间不要拔线。

需要：设备一台 · 可传输数据的 USB 线 · 桌面版 Chrome 或 Edge 的电脑。

请在电脑上使用 Chrome 或 Edge 打开本页；用数据线连接墨水屏后点击连接，在弹窗选择设备串口。

点击后进入安装窗口：确认清单 → 写入（约 1–2 分钟，含进度与日志）→ 完成后设备自动重启。过程中请保持页面打开、电脑唤醒、数据线不动。

找不到串口，或连接后无法写入？
先唤醒设备并保持 USB 连接；退出设备的 USB 读卡模式，关闭占用串口的其他程序（串口监视器、其他浏览器标签等）。仍未解决时，在设备「设置 → 升级和恢复」进入 BOOT 模式，再重新连接。也可以换一根支持数据传输的 USB 线、换一个 USB 接口后重试。
  1. 设备会自动重启。墨水屏断电后会保留旧画面，若屏幕没有变化，按住电源键强制关机，再开机即可。
  2. 把 EPUB / TXT 放进 TF 卡 Books/ 目录，把中文字体放进 Fonts/ 目录（内置字体只含常用汉字，缺字会显示为方框）。
  3. 从旧版本升级且书传在机内（非 TF 卡）的话，机内书区已重建，需重新传书；TF 卡书不受影响。
  4. 打开一本书，在排版菜单里调整字体与版式，开始阅读。
  • 资源包＝剧本与游戏内容（对话游戏 / 互动小说 / 步步高游戏），存放在 TF 卡的 games 文件夹；导入只是往卡里拷文件，不动固件、书籍与任何设置。
  • 两种方式任选：设备 USB 读卡（数据线直连，免拔卡）或 读卡器（拔 TF 卡插电脑）。zip 包原样拷入，不用解压。
  • 标注「需 v2.0」的包在旧固件上无法正常游玩，请先在「固件安装」标签升级。

读卡模式打不开，或电脑上不出现 U 盘？
先正常退出读卡模式重进一次；仍不行时把 TF 卡取出重插再试；设备浅睡唤醒（按一下电源键）后重连；最后再试重启设备。读卡模式与浏览器互不干扰，两个可以同时开。
  1. 关机后取出 TF 卡，装进读卡器插到电脑。
  2. 打开卡里的 games 文件夹（没有就新建一个），把 zip 原样拷入。
  3. 把卡装回设备开机，「应用 → 文绎 / 步步高游戏」即可看到。

无论哪种方式，导入完成后卡的其余内容（书籍、字体、存档）都不受影响；重复拷入同名包会直接覆盖为最新版。

网页刷机支持哪些浏览器？
桌面版 Chrome 或 Edge。网页刷机依赖 Web Serial API，Safari、Firefox 与手机浏览器暂不支持。
刷写会清空我的书籍和文件吗？
刷写只写入设备闪存，不处理 TF 卡，书籍与文件不受影响。安装弹窗里不勾选「擦除设备」时，设备内的设置与阅读数据也保持不变；勾选擦除则清空设备内部数据（TF 卡仍不受影响）。V1.0.2 起分区布局更新：从旧版本重新刷机后，机内书区会重建一次，机内存放的书需重新传入；TF 卡书籍与全部设置不受影响。
连接后找不到设备怎么办？
确认使用可传输数据的 USB 线，退出 USB 读卡模式，关闭占用串口的其他程序；在设备「设置 → 升级和恢复」进入 BOOT 模式后再连接。
写入中断了怎么办？
保持供电，重新连接并再安装一次。无法连接时，按上方说明进入 BOOT 模式，再重新选择串口刷写。
页面停在旧画面，是不是刷写失败了？
电子纸会保留旧画面，以安装窗口的进度为准。若设备按键毫无反应（偶发是重启时停在烧录待命模式），拔掉 USB 线重新插上即可恢复正常启动；必要时长按电源键强制重启。
刷机有风险吗？会失去官方保修吗？
刷写属自主操作，存在一定风险；写入前请备份重要数据。刷入非官方固件可能影响原厂保修，请自行斟酌。TF 卡上的书籍与文件不受影响。
