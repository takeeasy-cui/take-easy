剧作工坊

把网上的开源互动剧本，一键转成墨水屏设备可用的故事包。
文字游戏与互动小说同源——改包名前缀即可切换渲染方式。

全部在浏览器本地完成 · 剧本不会上传到任何服务器

📦
点击选择，或把 game/story/ 目录里的 .js 文件拖进来
支持多选：把所有场景剧本一次选中（如 prologue.js / chapter1.js / …）

来源示例：Do-fei/tegame（《重返十七岁》，MIT 开源）——GitHub 仓库页 Code → Download ZIP，解压后进 game/story/ 目录，把里面的 .js 文件全部选中即可。解析器支持「export const 场景 = {…}」结构的 ES 模块剧本。

text- .zip

留空则自动使用作品名称。前缀 text-＝对话流（立绘+对话框，适合带场景/立绘的剧作）；若想用书页排版阅读，可把前缀改成 novel-（同一套脚本，渲染方式不同）。

先上传剧本文件，校验通过后即可生成。
      怎么装进设备？ 生成的 zip 直接拷进 TF 卡根目录的 games 文件夹（不用解压，与游戏包放一起），设备「应用 → 文字游戏」里就会出现。需要含「文字游戏」应用的固件版本。
      文字游戏 vs 互动小说：有什么区别？

      本质是同一套脚本（story.txt），同一个内核解释，只是「渲染出口」不同：

      · text- 前缀（文字游戏）：对话流渲染——逐句进对话框，支持立绘、背景、选项 UI，适合《重返十七岁》这类 AVG 剧作；

      · novel- 前缀（互动小说）：书页排版渲染——走书阅读链路，正文分页、字号/行距可调，适合对话少的文本型互动小说。

      转换器不区分这两者，生成的都是 story.txt；改包名前缀即可切换设备上的渲染方式。当前转换器按对话剧作输出（text-）。

      哪些开源仓库可以用？

      当前适配 tegame 系（Do-fei/tegame 及其衍生），即剧本为「export const 场景 = { id, bg, palette, cast, next, script:[…] }」结构的 ES 模块。script 条目含 say/text（对话与旁白）、choice/options（选项分支）、goto（跳转）、id（分支锚点）、bg/cast（场景与立绘）。转换器会把这些语义映射为 story 引擎的 * label / * bg / * char / * choice / * goto / * ending 命令。

      其他仓库（Twine/ink/VNDS 等）正在逐步适配，敬请期待。

      转换后为什么只有文字，没有背景和立绘？
      当前版本聚焦「剧本语义」转换（story.txt），图片链路（背景/立绘素材转成设备灰度格式）正在开发中。缺图时设备会用占位框，不影响剧情试玩。后续版本将支持：背景图 / 立绘（images/bg、images/char）自动打包。
      数据存在哪里？
      上传的剧本和生成的 story.txt 只保存在当前浏览器的本地存储里（下次打开还在），所有转换计算都在你的电脑上完成，不经任何服务器。
      官方资源 · 拷进 TF 卡即玩

      资源下载

      官方出品的剧本与游戏包。把 zip 原样拷进 TF 卡根目录的 games 文件夹（不用解压），设备对应应用里就会出现。

      怎么导入？ 设备「传输 → USB 读卡」连电脑，把 zip 拷进 games 文件夹；或拔 TF 卡用读卡器拷。全部免解压（伏魔记也可以解压成 bbk-fmj 文件夹放进 games）。故事包入口在「应用 → 文绎」，伏魔记在「应用 → 步步高游戏」。从 1.0.x 升级的设备请先到在线刷机页刷入 v2.0（不勾选「擦除设备」，书籍与设置保留）。
